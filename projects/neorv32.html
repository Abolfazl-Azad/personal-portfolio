01 Overview

The NEORV32 Processor is a customizable, open-source 32-bit RISC-V compatible microcontroller and SoC written in platform-independent VHDL. Authored and maintained by Stephan Nolting, NEORV32 is widely utilized across both academia and industry for FPGA embedded computing, ASIC prototyping, and research.

Contributor Transparency: I am an independent open-source contributor to NEORV32. The project is created and maintained by Stephan Nolting. My contributions focused specifically on resolving verification test-suite edge cases and IEEE-754 compliance in merged PRs #1643 and #1644.

02 Problem Statement

Continuous regression testing in a clean-slate RISC-V core is critical for architectural reliability. Two distinct verification issues were identified in the upstream regression test suite:

  • Issue A (GPIO Loopback Verification): In the hardware verification testbench (processor_check), the GPIO input verification lacked a deterministic, repeatable input pattern and masked bit assertions. As a result, spurious bit reflections or uninitialized floating pins could cause false test reporting during automated simulation runs.
  • Issue B (Floating-Point Unit Special-Case Handling): In the floating_point_test C suite, boundary conditions for floating-point calculations had unreachable code segments and did not correctly evaluate signaling NaN (sNaN) vs. quiet NaN (qNaN) handling under the RISC-V 'F' extension specification.

03 Technical Objective

  • Develop a robust, repeatable test vector pattern for GPIO loopback verification with bitwise masking.
  • Ensure complete test coverage for edge-case floating-point values in accordance with the IEEE-754 standard and RISC-V 'F' ISA specifications.
  • Verify fixes locally across GHDL simulation before opening upstream pull requests.

05 Detailed Contributions

Enhanced processor_check by implementing a repeatable walking-1s and walking-0s input test vector and masked verification checks. This prevents uninitialized peripheral pin states from corrupting automated testbench passes.

06 Implementation Details

Example of the input validation enhancement integrated into the processor verification test harness:

neorv32/sw/example/processor_check/main.c C / RISC-V Test Suite 
// Enhanced GPIO Loopback Check with Masked Inversion
uint32_t test_pattern = 0xAA55AA55;
NEORV32_GPIO->PORT = test_pattern;

// Sample back via loopback register and verify with active mask
uint32_t sampled_in = NEORV32_GPIO->PORT;
uint32_t gpio_mask  = 0xFFFFFFFF;

if ((sampled_in & gpio_mask) != (test_pattern & gpio_mask)) {
  neorv32_uart0_printf("FAIL: GPIO loopback mismatch!\n");
  neorv32_uart0_printf("Expected: 0x%x, Received: 0x%x\n", test_pattern, sampled_in);
  return -1;
}
