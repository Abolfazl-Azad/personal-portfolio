01 Overview

Under the supervision of Dr. Shaghayegh Vahdat at the University of Tehran, this research investigates energy-efficient AI hardware through Compute-in-Memory (CIM) paradigms using emerging Resistive RAM (RRAM / memristor) crossbars. By executing vector-matrix multiplications directly inside the memory array via Ohm's Law and Kirchhoff's Current Law, CIM eliminates the classical von Neumann memory wall.

Our focus is twofold: developing hardware-aware 3-bit weight quantization strategies (mapping continuous weights to 8 physical conductance states), and evaluating subarray-level macro metrics (area, latency, and energy per MAC) using the NeuroSim C++ simulation framework.

02 Problem Statement

In deep learning accelerators, over 70–90% of total inference energy is consumed simply shuttling millions of weights from DRAM into arithmetic register files. While analog RRAM crossbars promise massive $O(1)$ computational efficiency, physical devices suffer from fundamental non-idealities:

  • Limited Precision: Real memristive devices cannot reliably sustain high-precision (e.g. 16-bit or 8-bit) continuous analog states due to device-to-device variability and conductance drift. Practical commercial RRAM cells reliably support only 2 to 4 bits of discrete conductance.
  • ADC Energy Dominance: Analog column currents must be converted back to digital domain via column ADCs. At high resolutions (e.g., >8 bits), ADCs consume up to 80% of total macro area and power.

Thus, neural network weights must be aggressively quantized down to fixed 3-bit discrete representations (8 conductance states) with minimal loss in model classification accuracy.

03 Research Objective

  • Formulate and evaluate a hardware-aware weight clustering and quantization pipeline targeting exactly 8 discrete conductance states ($G_0$ to $G_7$).
  • Quantize baseline convolutional architectures (VGG8 on CIFAR-10) using PyTorch, exploring post-training quantization and Quantization-Aware Training (QAT).
  • Set up an inference simulation path in NeuroSim with a 128 × 128 RRAM subarray, 5-bit column ADCs, and 32nm CMOS technology parameters to estimate area, latency, and dynamic energy.

  • PyTorch Quantization Pipeline: Built a Python/PyTorch workflow to quantize convolutional and dense weights into 8 non-uniform cluster levels corresponding to physical memristor states.
  • Clustering Evaluation: Assessed k-means and linear quantization baselines to minimize distortion and protect accuracy on CIFAR-10 with VGG8.

06 Implementation Details

Example of the hardware-constrained clustering and quantization routine:

quantize_3bit_rram.py (PyTorch / Python) Clustering Pipeline 
import torch
import numpy as np
from sklearn.cluster import KMeans

def quantize_weights_3bit(weight_tensor):
    """
    Quantizes a floating-point PyTorch weight tensor into 8 discrete
    conductance states (3-bit) via non-uniform k-means clustering.
    """
    flat_weights = weight_tensor.detach().cpu().numpy().reshape(-1, 1)
    
    # Fit 8 clusters corresponding to states G0 .. G7
    kmeans = KMeans(n_clusters=8, n_init=10, random_state=42).fit(flat_weights)
    cluster_centers = np.sort(kmeans.cluster_centers_.flatten())
    
    # Map weights to nearest discrete center
    q_weights = cluster_centers[kmeans.labels_].reshape(weight_tensor.shape)
    return torch.from_numpy(q_weights).to(weight_tensor.device)

07 Verification and Benchmarking

  • Floating-Point Baseline: Evaluated FP32 unquantized VGG8 model accuracy on CIFAR-10 (~90% test set baseline).
  • Direct 3-Bit Quantization: Observed initial accuracy drop under naive uniform quantization, demonstrating the necessity of non-uniform clustering and Quantization-Aware Training (QAT).
  • NeuroSim Sanity Checks: Verified that total column currents stayed within ADC full-scale saturation limits to avoid signal clipping in the analog domain.
