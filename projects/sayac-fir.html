SAYAC: 31-Tap FIR Hardware Accelerator & DMA Engine

Electronic System-Level (ESL) integration of a pipelined 31-tap FIR filter accelerator with an autonomous DMA controller using SystemC TLM 2.0 transaction-level modeling.

01 Overview

In modern embedded systems, offloading high-throughput DSP filtering from the main CPU to dedicated hardware accelerators is critical for maintaining real-time deadlines. This project implements a 31-tap Finite Impulse Response (FIR) filter accelerator integrated with a Direct Memory Access (DMA) controller within the SAYAC processor memory map.

Using SystemC TLM 2.0, the complete system was modeled at the transaction level, enabling rapid hardware/software co-design, bus transaction profiling, and architectural verification prior to RTL synthesis.

02 Problem Statement

Executing an N-tap FIR filter in pure software requires $N$ multiplications and $N-1$ additions per output sample:

y[n] = ∑_{k=0}^{N-1} h[k] · x[n-k]

When the CPU performs these operations via software loops, two major bottlenecks emerge:

  • Compute Saturation: Arithmetic ALUs are occupied by repetitive MAC operations, starving other real-time operating system threads.
  • I/O Bottleneck: Programmed I/O (polling or per-sample interrupts) wastes significant clock cycles on bus transfer overhead.

03 Technical Objective

  • Design a cycle-accurate 31-tap FIR hardware accelerator with symmetric coefficient optimization.
  • Integrate an autonomous DMA engine that streams input sample blocks directly from system RAM into the accelerator.
  • Implement memory-mapped register interfaces for software control (source address, destination address, block size, status, and interrupt triggers).
  • Validate the transaction-level design in SystemC against an exact golden mathematical model in Python.

05 My Contributions

  • Accelerator SystemC Modeling: Designed the 31-tap FIR filter module with internal 16-bit shift registers and coefficient arrays using SystemC TLM 2.0.
  • DMA Integration: Constructed the DMA transaction engine to read input sample blocks from memory, pump them into the filter FIFO, and write back filtered results autonomously.
  • Memory-Mapped CSRs: Defined the register specification and decoding logic for configuration, status polling, and interrupt requests.
  • Verification Harness: Created a comprehensive verification testbench that fed multi-frequency synthetic audio/sinusoidal streams and verified sample-by-sample output accuracy.

06 Implementation Details

Below is a code excerpt demonstrating the core TLM 2.0 blocking transport implementation handling data sample streaming:

fir_accelerator.cpp (SystemC TLM 2.0) Accelerator Module 
void fir_accelerator::b_transport(tlm::tlm_generic_payload& trans, sc_time& delay) {
  tlm::tlm_command cmd = trans.get_command();
  uint64_t adr         = trans.get_address();
  uint8_t* ptr         = trans.get_data_ptr();
  unsigned int len     = trans.get_data_length();

  if (cmd == tlm::TLM_WRITE_COMMAND) {
    int16_t sample;
    memcpy(&sample, ptr, sizeof(int16_t));

    // Shift register propagation
    for (int i = 30; i > 0; --i) {
      shift_reg[i] = shift_reg[i - 1];
    }
    shift_reg[0] = sample;

    // Convolution MAC accumulate
    int32_t acc = 0;
    for (int i = 0; i < 31; ++i) {
      acc += (int32_t)coeffs[i] * shift_reg[i];
    }
    last_output = (int16_t)(acc >> 15); // Scale fixed-point result
    trans.set_response_status(tlm::TLM_OK_RESPONSE);
  }
  delay += sc_time(10, SC_NS); // Simulated cycle delay
}

07 Verification and Testing

  • Impulse Response Verification: An ideal unit impulse $\delta[n]$ was injected to observe that output samples identically matched the 31 filter coefficients $h[n]$.
  • Frequency Domain Test: Injected dual-tone sinusoidal test vectors (passband $f_1 = 500\,\text{Hz}$ and stopband $f_2 = 8\,\text{kHz}$) to confirm >40 dB attenuation of unwanted out-of-band harmonics.
  • DMA Buffer Boundaries: Verified zero-length transfers, odd-aligned buffer addresses, and continuous burst operations without data corruption.
