# Abolfazl Azad - Portfolio & CV

A vanilla HTML/CSS/JS static portfolio designed for performance, accessibility, and clean visual representation of digital systems engineering.

## DEPLOYMENT

This site is statically generated and hosted via **Cloudflare Pages**. 

- **Build command**: `none` (leave empty)
- **Build output directory**: `/`
- **Production branch**: `main`

The custom domain will be connected directly through Cloudflare Pages.

*Note: Once the final domain is chosen, `YOUR-DOMAIN-HERE` must be updated in `index.html`, `pages/cv.html`, and `sitemap.xml` for correct SEO canonicalization.*
